# CryptoTrack

Research + implementation project.

Baseline: Zhou et al., "Multi-source data driven cryptocurrency price movement prediction and portfolio optimization."

CryptoTrack improvements:
1. Probabilistic forecasts instead of only binary signals.
2. Walk-forward validation with a separate validation stage.
3. Transaction-cost-aware backtesting.
4. Risk, drawdown and turnover reporting.
5. Ablation experiments for information sources.

Rule: no numerical result goes into the paper until generated by the reproducible pipeline.
